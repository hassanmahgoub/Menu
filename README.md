# Menu Website (QR Menu)

A simple phone-friendly Arabic menu website to open via QR code.

## Files
- `index.html` – menu content (edit items, prices, calories)
- `styles.css` – styling

## How to use
1. Edit `index.html`:
   - Change **اسم المطعم** and **امسح رمز الـ QR لعرض المنيو**.
   - Replace the example items with your real items (name + price + calories).
2. Host the folder as static files (examples):
   - GitHub Pages
   - Netlify
   - Any static hosting
3. Generate a QR code that points to your hosted URL.

## QR
- If you already have the QR image, you can print it and scan to open this page.
- If you want, you can also add your QR inside the page, but you’ll need to provide the URL.
